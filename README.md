# Expanded-Galaxy

## Information
- Developer: sugarbuzz1
- Game Version: 1.2.10
- PML Version: 0.12.3.31
- Mod Version: 1.2.4
- MP Requirements: Host & Clients need the mod

## Installation
- Install PulsarModLoader
- Install Talent Mod
- Go to \PULSARLostColony\Mods
- Move ExpandedGalaxy.dll into folder
- Rename Talents.dll so it sorts above ExpandedGalaxy.dll

## Features
- This overhaul mod is absolutely massive, and listing all of the features here would take up a lot of space. An intractable handbook spawns in the crew quarters/lounge of every ship that lists all of the changes and additions from this mod in detail.
